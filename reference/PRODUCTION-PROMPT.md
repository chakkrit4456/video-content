## สเปกงาน (ห้ามเปลี่ยนถ้าผู้ใช้ไม่สั่ง)

- แนวตั้ง 9:16, 1080×1920, 30 fps, ยาว **3.5–4 นาที ต่อ EP** (ประมาณ 50–55 บรรทัด)
- **ตัวนับวัน**: HUD มุมขวาบนแสดง "วันที่ N / 30" แทนนาฬิกา ทุกครั้งที่ขึ้นวันใหม่ ให้มีการ์ดคั่นวัน 0.8–1 วินาที
  (เลขวันใหญ่สีแดง + เสียงป๊อป) และให้ภาพบอกเวลาที่ผ่านไป: เคราขึ้น, ของในตู้ลด, ขีดนับวันบนผนัง, ต้นไม้เหี่ยว
- โครง EP: hook (คำถาม "คุณจะรอดได้กี่วัน") → วันละ 1 กฎ (กฎข้อที่ 1, 2, 3 …) → จุดพลิกวันสุดท้าย → cliffhanger ไป EP หน้า
- ภาษา: เสียงพากย์ **ไทย** + ซับไตเติล **ไทย** (เปลี่ยนเป็นซับอังกฤษได้ถ้าผู้ใช้สั่ง)
- ผู้บรรยายคนเดียว พูดด้วยสรรพนาม "คุณ" ตลอดเรื่อง
- เสียงพากย์: `edge-tts` เสียง `th-TH-NiwatNeural` (ชาย) หรือ `th-TH-PremwadeeNeural` (หญิง) เลือกแล้วใช้ทั้งซีซัน
- ลุค: ไดโอรามาจิ๋วโทนอุ่น สีด้าน ไฟอุ่นมี Glow, TiltShift บน-ล่าง, เกรนเบาๆ + vignette, กล้อง push-in ช้าๆ ทุกช็อต
  ซีรีส์นี้ให้ปรับโทนเป็น **อุ่นตอนกลางวัน / เย็นอมเขียวตอนกลางคืน** เพื่อให้เข้ากับแนวซอมบี้
- ตัดทุก 1.5–3 วินาที กล้องไม่นิ่งสนิท
- แคปชัน: ครั้งละ 1 วลี (≤ 7 คำ) สีครีม กลางล่าง (y≈1230) คำสำคัญเป็นชิปแดง/ตัวอักษรอำพัน ใต้แคปชันคือซับเต็มประโยค
  วางหน้าคนและพร็อพไว้เหนือ ~1150px หรือใต้ ~1500px
- เสียง: ไม่มีเพลงเป็นค่าเริ่มต้น ใช้ room tone ต่อเนื่อง + เสียงป๊อปกระดาษตอนการ์ดขึ้น + SFX ตามจังหวะเรื่อง
- ความดัง −14 LUFS (±1), peak ≤ −1 dBFS
- ห้ามอีโมจิ ห้ามตัวหนังสือพองหรือขอบ 3D
- ความรุนแรง: **light** (เลือดติดตัว rig ได้เล็กน้อย ไม่โชว์บาดแผลชัดๆ ไม่มีชิ้นส่วนร่างกาย)

## ขั้นที่ 2: เขียนบท (skill `story-rule-script`)

### 2.1 สูตร
- **Hook** (บรรทัดที่ 1–2): กฎที่สวนสัญชาตญาณ "ถ้า X เกิดขึ้น ห้าม Y" ภายใน 2 วินาทีแรก
- **ข้อเท็จจริงจริงที่มีตัวเลข** แล้วแปลงเป็นการกระทำทันที (ตรวจกับแหล่งข้อมูลจริง เก็บแหล่งที่มาไว้ในโน้ตของตอน)
- **คู่หู (สัตว์)** สังเกตเห็นอันตรายก่อนเสมอ
- **เวลาที่เดินบนจอ** (HUD "วันที่ N / 30") เช่น วันที่ 1 → 2 → 3 → 7 → 10 …
- **จุดพลิก** ใกล้จบ: "คุณทำถูกทุกอย่าง ยกเว้นอย่างเดียว" + รายละเอียดทางกายภาพที่ปูไว้ตั้งแต่ต้น (ต้อง "เห็น" บนจอ ไม่ใช่อธิบาย)
- **Cliffhanger** = hook ของตอนถัดไป ในรูป "ถ้า... ห้าม..."
- ตอนต่อเนื่อง: เปิดด้วยการทวน cliffhanger ตอนก่อน 1 บรรทัดแล้วไปต่อเลย
- 1 ตอน = 1 กลไก ตั้งชื่อสิ่งนั้นครั้งเดียวแล้วเรียกเหมือนเดิมตลอด

### 2.2 รูปแบบไฟล์ `script.md` (ต้องตรงเป๊ะ เพราะเครื่องมือจับเวลาอ่านตารางนี้)
```
| # | VO | Subtitle |
|---|---|---|
| 1 | ถ้าเห็นข่าว ว่ามีคนกัดกัน ห้ามออกไปซื้อของ | ถ้าเห็นข่าวว่ามีคนกัดกันในเมือง ห้ามออกไปซื้อของตุน |
```
- 1 แถว = 1 ประโยคพูด, รวม 50–55 แถว, พูดแล้วยาว ≈ 3.5–4 นาที ทุกวันใหม่ขึ้นต้นแถวด้วย "วันที่ ..."
- **ภาษาไทยไม่มีเว้นวรรคระหว่างคำ** ให้เว้นวรรค "ระหว่างวลี" เท่านั้น (1 วลี = 1 แคปชัน, ≤ 7 คำ/วลี)
- ตัวเลขในช่อง VO เขียนเป็นคำ ("สามสิบวินาที") ช่อง Subtitle ใช้ตัวเลขได้ ("30 วินาที")
- ห้ามช่วงตัวเลข ("80 ถึง 85" → "เกินแปดสิบ")
- คำทับศัพท์/ชื่อเฉพาะ เขียนตามเสียงที่อยากให้ TTS อ่าน (เช่น "เคียวอาร์" ไม่ใช่ "QR")
- ใต้ตารางเขียนโน้ต 3 บรรทัด: อะไรจริง/อะไรแต่ง, ปูอะไรไว้สำหรับจุดพลิก, cliffhanger ปูไปเรื่องอะไร

### 2.3 เช็กลิสต์ก่อนส่งบท
- [ ] Hook เป็นกฎ และเข้าใจได้ในบรรทัดแรก
- [ ] ทุกจังหวะเข้าใจได้จากเสียง + ภาพ โดยไม่ต้องมีการ์ดอธิบาย
- [ ] ข้อเท็จจริงทุกข้อมีแหล่งที่มา
- [ ] คู่หูเห็นก่อนอย่างน้อย 1 ครั้ง
- [ ] รายละเอียดจุดพลิกถูกปูไว้ในช่วงแรกของเรื่อง และเห็นได้บนจอ
- [ ] Cliffhanger เป็นกฎใหม่ "ถ้า... ห้าม..."
- [ ] ความยาว 50–55 แถว, นับวันครบถึงวันสุดท้ายของ EP, ทุกวลี ≤ 7 คำ
- **หยุดส่งบทให้ผู้ใช้อ่าน รอ "ผ่าน"**

### 2.4 แคปชันสำหรับโพสต์ (ร่างให้ด้วย)
บรรทัด hook + ใบ้จุดพลิกโดยไม่สปอย + คำถามชวนคอมเมนต์ + "(เรื่องแต่ง)" + แฮชแท็ก 5–7 อัน ไม่มีอีโมจิ

## ขั้นที่ 3: เสียงพากย์ไทย → จับเวลา

ภาพใช้เวลาจาก `src/lines.json` **เท่านั้น** ห้ามจับเวลาด้วยมือในโค้ด

```
python "<scripts>/tts.py" edge --voice th-TH-NiwatNeural
python "<scripts>/transcribe.py" vo/takeA.mp3 --lang th
python "<scripts>/align.py" vo/takeA.mp3          # ต้องได้ overlaps: 0
# แก้ vo/pauses.json  {"บรรทัด": วินาทีที่เพิ่ม}
#   +0.4–0.6 หลังประโยคหมัดเด็ด, +0.8–1.0 ก่อนจุดพลิก
python "<scripts>/splice.py"                       # ได้ vo/vo_aligned.wav + src/lines.json
```

ตรวจเสียงพากย์ไทย:
1. อ่านผล transcribe เทียบกับบททุกบรรทัด คำไหนสงสัยต้อง **ฟังจริง**
2. ปัญหาที่เจอบ่อยกับ TTS ไทย: อ่านตัวเลข/ตัวย่อผิด, ตัดคำผิดที่, วรรณยุกต์เพี้ยนในคำทับศัพท์
   แก้โดยเขียนคำใหม่ตามเสียงในบท แล้วใช้ `python "<scripts>/revoice.py"` สลับเฉพาะบรรทัดนั้น (เวลาไม่ขยับ)
3. แคปชันขึ้นก่อนเสียง = ตัดแบ่งผิด แก้ `t`/`end` ของบรรทัดนั้นใน `vo/lines.json`
   หาช่องเงียบจริงด้วย `python "<scripts>/tools.py" gap vo/takeA.mp3 t0 t1` แล้วรัน splice.py ใหม่
4. ความยาวรวมต้องอยู่ในช่วง 3.5–4 นาที ถ้าเกิน ตัดบรรทัดในบท ไม่ใช่เร่งเสียง

5. รายงานสั้น: ทำอะไรไป, จุดที่ยังไม่สมบูรณ์ (known gaps)
