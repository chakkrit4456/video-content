## EP3

## EP4
```
ถ้าต้องหนีออกจากค่ายตอนกลางคืน ห้ามใช้ประตูหน้า

EP4 วันที่ 91–120
ป่ามืด ลำธารเย็น และไฟแดงบนยอดเสาส่งวิทยุ
คุณกับฝนหาคนที่ตามหามาตลอดเจอ
แต่มีของชิ้นเล็กๆ ที่คุณพกติดมือออกจากค่าย และมันยังไม่หยุดทำงาน
```

## EP5 (ตอนจบ)
```
ถ้าต้องข้ามน้ำหนี ห้ามลงเรือพร้อมกันทุกคน

EP5 ตอนจบ วันที่ 121–150
เรือหนึ่งลำ รับได้สองคน
มีคนหนึ่งเลือกเป็นเสียงล่อให้ทุกคนข้ามไปได้
150 วันที่ผ่านมา ทุกด่านบอกให้คุณทิ้งแมว และคุณไม่เคยทำตามเลยสักครั้ง

ขอบคุณที่รอดมาด้วยกันครบ 150 วัน
```
